# DevKit

**A collection of useful tools built for developers.**

DevKit is an open-source collection of practical developer utilities designed to make everyday development tasks faster, easier and more accessible.

No accounts. No unnecessary complexity. Just useful tools.

## ✨ Features

- JSON Formatter & Validator
- UUID Generator
- Base64 Encoder & Decoder
- JWT Decoder
- SHA-256 Hash Generator
- Regex Tester
- Unix Timestamp Converter
- Color Converter (HEX, RGB, HSL)

More tools coming soon.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- Vitest

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS)
- npm

### Installation

```bash
git clone https://github.com/ttvmagma/devkit.git
cd devkit
npm install
npm run dev
```

## 🔒 Privacy

DevKit is designed with privacy in mind.

All tool processing happens locally in your browser. User inputs are not transmitted to external servers.

## 🧪 Testing

```bash
npm run test
```
